03 / YAZILIMINI SEÇ

Kitaptaki kod, bağımsız paket.

Python Bu paketle çalıştırıldı

Python 3, pandas, numpy ve scipy gerekir. python dogrula.py kitabın analizini çalıştırır ve bağımsız hesapla karşılaştırır. Yalnız analiz için:

python companion/spss/python/b01.py
Python kodu
import pandas as pd
import numpy as np
from scipy import stats

d = pd.read_csv("companion/spss/csv/b01.csv")
assert not d.isna().any().any()
d["school"] = pd.Categorical(d.school.map({1:"GP", 2:"MS"}))
d["sex"] = pd.Categorical(d.sex.map({1:"F", 2:"M"}))
d["studytime"] = pd.Categorical(
    d.studytime, categories=[1, 2, 3, 4], ordered=True)
d.info()
print(d.isna().sum())
print(d.school.value_counts()); print(d.sex.value_counts())
print(d[["age", "g1", "g2", "g3"]].agg(
    ["count", "mean", "std", "min", "max"]))

d <- read.csv("companion/spss/csv/b01.csv")
stopifnot(!anyNA(d))
d$school <- factor(d$school, 1:2, c("GP", "MS"))
d$sex <- factor(d$sex, 1:2, c("F", "M"))
d$studytime <- ordered(d$studytime, levels=1:4)
str(d)
print(colSums(is.na(d)))
print(table(d$school)); print(table(d$sex))
x <- d[c("age", "g1", "g2", "g3")]
print(sapply(x, function(v) c(n=length(v),
  mean=mean(v), sd=sd(v), min=min(v), max=max(v))))

06 / KENDİNİ DENE

Hesaptan önce gerekçeni yaz.

1. 395 kayıt bir evren midir, örneklem midir?
Tanımladığımız hedefe bağlıdır. Dosyanın tamamını betimliyoruz; dosyanın daha geniş bir öğrenci evrenini temsil ettiğini ayrıca göstermedik.
2. Sıfır notları çıkarırsak aynı soruyu mu yanıtlarız?
Hayır. Pozitif notlu alt gruba geçeriz. Bu uygulamada sıfırlar eksik değer sayılmaz ve korunur.
3. GP=1, MS=2 kodlarının ortalaması neyi söyler?
Okul adı nominaldir. Kodlar bir nicelik ölçmez; kategori frekansı ve yüzdesi raporlanır.
4. Aynı id'yi Portekizce dosyasında bulmak eşleşme midir?
Hayır. id burada oluşturulmuş sıra numarasıdır. Kişi eşleştirmesi kanıtı değildir.
5. Python sonuçları tutunca R/SPSS de doğrulanır mı?
Hayır. Yeni paket her yazılımda çalıştırılmalı; kapsam, veri açma, sürüm ve yuvarlama farkları kaydedilmelidir.
