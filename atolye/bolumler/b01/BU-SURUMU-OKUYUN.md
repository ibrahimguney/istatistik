# B01 yayın önizlemesi

Beş yapay gözlem; 395 öğrencilik UCI uygulaması değildir.
Özgün 13 dosya eski manifest hashleriyle korunur. Eski README ve DOGRULAMA
belgelerindeki yayın/eksiklik ifadeleri tarihsel kaynak kopyasının durumudur.
Bu önizlemede eksik analiz.sps, hash ile doğrulanan analiz.sps.txt kopyasından
tamamlandı. Güncel kapsam YAYIN-KONTROLU.json içindedir. Python çalıştırıldı;
R/SPSS çalıştırılmadı. Otomatik lisans ataması veya GitHub yayını yapılmadı.

ZIP'i açın; b01/ornek-01 içinde python cozum.py --check çalıştırın.
R için aynı klasörde Rscript cozum.R --check kullanın. SPSS çalışma
dizinini aynı klasöre ayarlayıp analiz.sps dosyasını çalıştırın.
Python için pandas gerekir; sürüm kaydı ciktilar/python/calistirma.txt içindedir.
